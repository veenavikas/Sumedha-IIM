01 — Current site audit
What the live site has — and what it's missing

The current mysumedha.com is a WordPress site built with Slider Revolution and a generic theme. It is functional but critically undersells the institution. Below is a full gap analysis based on the live pages scraped.

Critical problems
  • Homepage returning 500 server error intermittently — killing lead generation
  • All course links point to same single URL (diploma-in-hotel-management/) — broken UX
  • No individual course detail pages — no curriculum, no fees, no apply CTA per course
  • No placement/recruiter page — biggest trust signal completely absent
  • No faculty/team page
  • No campus gallery with real infrastructure photos
  • No WhatsApp or lead capture on homepage — only on inner pages
  • Slider Revolution plugin — heavy, slow, mobile-broken
  • WordPress vulnerability surface — security risk
  • Zero SEO meta descriptions or structured data
  • No mobile-first design — text too small on phones
  • Testimonials show logo only, no real student names or photos
  • Chairman's Message page exists but feels generic and unpolished
What exists to keep
  • Real contact details — 8886197778, 9966319916, info@mysumedha.com
  • Physical address — 4th Floor, 2nd Line, Diamond Park, Dwarakanagar, Vizag
  • Operating hours — Mon–Sun 9AM–8PM (7-day availability)
  • 7 courses correctly named and structured
  • Vision & Mission copy is usable (needs polishing)
  • WhatsApp chat widget concept is correct
  • Instagram + YouTube channel links are live
  • Collaborations page structure exists
  • Gallery and Videos pages exist (need new content)
  • Admission Form page exists (needs redesign)
  • Privacy Policy and Terms pages exist
  • NSDC / Skill India approval — strong trust signal to promote more
Current nav structure

Home → About (Chairman's Message) → Programmes → Admission (Prospectus, Admission Form) → Career (Collaborations) → Media (Gallery, Videos) → Contact

Problems: "Career" is used for a generic page about hospitality careers — confusing. "Media" is buried. No placements, no faculty, no campus life section, no blog/news, no dedicated enquiry flow.

Performance targets (Lighthouse)
  • Performance ≥ 90. FCP < 1.5s on broadband. LCP < 2.5s. CLS < 0.1.
  • Accessibility ≥ 95. WCAG 2.1 AA. All images have alt text. Keyboard navigable. 4.5:1 contrast minimum.
  • SEO ≥ 95. Unique meta title + description per page. Open Graph tags for all pages. Sitemap.xml + robots.txt. Schema.org EducationalOrganization JSON-LD on homepage.
  • Mobile-first. Tested at 375px, 768px, 1280px, 1440px. Touch targets ≥ 44px. No horizontal scroll.
  • Security: no WordPress, no plugin vulnerabilities. HTTPS enforced. CSP headers via Vercel config.
